🔬 配平 combustion、跟踪尾气里的 pollutant

① 选 alkane 与 O₂ 充足程度，观察 complete / incomplete combustion 的配平 equation，可切换整数或自己填系数练习；② 观察从引擎到 catalytic converter 的尾气点流，点击 pollutant 查看其来源、危害与催化转化 equation。

1. 选 alkane（C 数 n = 1 ~ 8）
2. 调节 O₂ 供氧量（充足程度）
充足 complete
① 充足 (complete → CO₂) ② 不足 (incomplete → CO) ③ 极不足 (severely limited → C)
配平 chemical equation：
✍️ 自己填系数练习 填入正数（支持 ½ 如 12.5、12½、25/2，或全式 ×2 的整数）
+ O₂ → + H₂O
converter 前（exhaust pipe 里的点数）
CO × 0 NOₓ × 0 HC × 0
→ converter →
converter 后（tailpipe 里的点数）
CO / NOₓ / HC × 0 CO₂ / N₂ / H₂O × 0 CO₂ 仍然排出
⚠️ 易错点：catalytic converter 无法除去 CO₂

converter 除去了 toxic 的 CO、造成 acid rain / photochemical smog 的 NOₓ 和 unburnt hydrocarbons，但含 C 的 pollutant 最后都被 oxidise 成 CO₂，而 CO₂ 是 greenhouse gas，converter 对它无能为力——要少排 CO₂ 只能少烧 fuel。
