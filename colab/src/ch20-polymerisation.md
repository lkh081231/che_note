<!-- md #polymers -->
## 20.1 Addition polymerisation

<!-- md #rx-polymerisation -->
### A. poly(ethene) 与 poly(chloroethene)

{{lo 20.1.1}}

{{rxn-in polymer}}

- **monomer**：能连成 polymer 的小 molecule；**polymer**：由许多 repeat unit 连成的长链 molecule；
- **addition polymerisation**：许多含 C=C 的 monomer 连成长链，polymer 是**唯一的 product**（不放出小 molecule）；
- n CH₂=CH₂ → –[CH₂–CH₂]ₙ–　**poly(ethene)**
- n CH₂=CHCl → –[CH₂–CHCl]ₙ–　**poly(chloroethene), PVC**
- n CH₂=CHCH₃ → –[CH₂–CH(CH₃)]ₙ–　poly(propene)（syllabus 14.2.2(d) 的例子）

polymer 里**没有 C=C 了**（π bond 全部变成链里的 σ bond），所以 poly(ethene) 是 saturated 的：它**不和 electrophile 反应**、不使 Br₂(aq) 褪色——和 ethene 正相反（9701/22 Oct/Nov 2024 的「why ethene reacts with electrophiles but poly(ethene) does not」：ethene 有 π bond / 高 electron density 的 C=C，poly(ethene) 没有）。

<!-- md #repeat-unit -->
### B. 由 monomer 写 repeat unit

{{lo 20.1.2}}

**repeat unit**：连续重复就能拼成整条链（两端除外）的最小 atom 组。

画法（三步）：

1. 把 monomer 的 **C=C 两个 C** 横着放，四个取代基一上一下画出来（照 monomer 原样，不要挪位置）；
2. C=C 改成 **C–C**；
3. 两端各画一根**伸出去的 bond**（continuation bond），可以加方括号和 n。

判分（9701/21 May/June 2026 Q5(f)，poly(chloroethene)）：–[CH₂–CHCl]– 即可；**括号和 n 不要求**；伸出的 bond 要和主链区分得开（虚线、明显更长，或穿过括号）。只有两个主链 C：取代基（Cl、CH₃、COOCH₃、CN …）**全部挂在这两个 C 上**，不进主链。

例：2-chloroprop-1-ene CH₂=C(Cl)CH₃ → –[CH₂–C(Cl)(CH₃)]–（9701/22 Feb/Mar 2024）；methyl 2-methylprop-2-enoate CH₂=C(CH₃)COOCH₃ → –[CH₂–C(CH₃)(COOCH₃)]–（PMMA，9701/23 May/June 2025）；CH₂=C(CN)COOC₂H₅ → –[CH₂–C(CN)(COOC₂H₅)]–（9701/22 Feb/Mar 2026）。

<!-- md #monomer -->
### C. 由一段 polymer 找 monomer

{{lo 20.1.3}}

1. 在主链上找重复的部分：addition polymer 的主链**全是 C**，每 **2 个主链 C** 是一个 repeat unit；
2. 取两个相邻的主链 C 和挂在上面的取代基，把它们之间的 C–C 改回 **C=C**，两端伸出的 bond 去掉；
3. 如果相邻的 repeat unit 不一样（例如交替出现），说明是两种 monomer 共聚（copolymer）：分别还原。

例：–CH₂–CH(CH₃)–CH₂–CH(CH₃)– → 每两个 C 一组 → CH₂=CHCH₃（propene）。

<!-- md #disposal -->
### D. poly(alkene) 的 disposal

{{lo 20.1.4}}

| 问题 | 原因 |
|---|---|
| **non-biodegradable**（在 landfill 里几百年不分解） | poly(alkene) 本质上是巨大的 alkane：strong、non-polar 的 C–C / C–H bond，化学上很不活泼，微生物也分解不了（{{xref ch14#unreactive 14.1 E}}） |
| **harmful combustion products** | 焚烧放出大量 CO₂（greenhouse gas），incomplete combustion 产生 toxic 的 CO；**PVC** 燃烧还放出 **HCl**（acidic、腐蚀性）和 toxic 的 **dioxins** |

这些「不活泼」恰好也是 poly(alkene) 好用的原因（耐腐蚀、耐用）。

Cl₂ reacts readily with propene to form **K**, 1,2-dichloropropane. **K** can be used to form **L**.
![Fig. 2.1](passyear/extracted/ch09-periodicity/img/9701_m24_22_fig2-1.png)

#### Q2(d)(iii) [1]

Draw **one** repeat unit of the addition polymer that forms from **L**.

::: answer
**答案**（答案是图，见 MS 渲染页 `_img/9701_m24_22_msp07.png`）

**L** 是 2-chloroprop-1-ene，CH₂=C(Cl)(CH₃)（C1 为 =CH₂，C2 同时接 Cl 与 CH₃ 支链）。加成聚合的
重复单元用两端虚线表示主链延伸：

<pre>   Cl   H<br>   |    |<br>---C —— C---<br>   |    |<br>  H₃C   H</pre>

左边碳（来自单体 C2）同时接 Cl（上）和 CH₃（下），右边碳（来自单体 C1）上下各接一个 H。

:::
