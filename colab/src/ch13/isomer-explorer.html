isomer 枚举器：一个 molecular formula 有几个 isomer？

选一个 molecular formula，先写下你觉得有几个 isomer，再揭晓全部 skeletal formula。卡片按 functional group 分组，每张卡的彩色标签说明它与上一张是哪一种 isomer；打开 stereoisomer 开关，cis / trans 和一对 enantiomers 会拆成两张卡。

彩色标签 = 与上一张的关系： chain positional functional group cis / trans enantiomer * chiral centre

chiral centre 与 cis / trans 的判断见 {{xref ch13#optical 13.4 C}}、{{xref ch13#find-isomerism 13.4 D}}。
