为什么 C=C 不能转：σ bond 能转，π bond 不能 拖动旋转 · 滚轮缩放

3D 没有加载（）。下面的 slider、overlap 读数、「沿 C2=C3 轴看」的图和结构式照常可用。

butane：绕 C2–C3 single bond 转
σ overlap：100%（不随 θ 变）

but-2-ene：绕 C2=C3 double bond 转
π overlap ∝ |cos θ|：100%
沿 C2=C3 轴看过去
● C2 的 p orbital（前）
● C3 的 p orbital（后，虚线）
两个 p 轴平行 → overlap 最大；互相垂直 → 0

butane 转 180° 只是换了一个 conformation，还是同一个 compound；but-2-ene 转到 180° 却变成了另一个 compound（cis → trans），而中途 90° 时 π overlap = 0，等于先把 π bond 断开。室温下 molecule 的能量不够断 π bond，所以 cis 和 trans 不会互变：restricted rotation about the C=C。

两个 CH₃ 在 C=C 的两侧（对角）

C2 和 C3 上都各连着 H 和 CH₃ 两个不同的 group，所以「CH₃ 在同侧还是两侧」是两种不同的排列；π bond 又把它们锁住 → 两个 stereoisomers。它们是不同的 compounds，mp、bp 都不同。

C1 上两个 group 都是 H：把它们对调，得到的还是同一个 molecule

2-methylpropene
{{chemfig \chemfig{@{c1}C(-[:120]@{ha}H)(-[:240]@{hb}H)=[:0]@{c2}C(-[:60]@{m1}CH_3)(-[:-60]@{m2}CH_3)}}}

C1 上两个 H、C2 上两个 CH₃：每个 C 都有一对相同的 group

C=C 照样不能转，但只要其中一个 C 连着两个相同的 group，「同侧 / 两侧」就分不出来 → 没有 cis/trans。判断时要检查 C=C 的每一个 C 是否都连着两个不同的 group。
