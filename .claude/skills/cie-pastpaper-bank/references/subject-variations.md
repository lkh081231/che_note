# 按科目要改什么

参考实现是化学 9701。下面是换科目时**必须重新决定**的地方。
所有「实测」数据都来自化学，别的科目要自己测一遍。

---

## 一、Mark scheme 的结构（改动最大的一处）

化学的 MS 是四栏表 `Question / Answer / Marks / Guidance`，逐点给分，可以逐点抄。
**这不是所有科目的样子。**

| 科目类型 | MS 形态 | 产物要怎么变 |
|---|---|---|
| 化学 9701 / 物理 9702 / 生物 9700 | point-based 四栏表 | 逐点抄 Answer + Marks；Guidance 精简（只留 A/R/I、ecf、max 等影响判分的，删同义词罗列和考官流程话术） |
| 数学 9709 / 进阶数学 9231 | 带 **M / A / B 标记**（Method / Accuracy / Independent）+ 逐步骤 | **M/A/B 标记比化学的 Guidance 重要得多，绝不能精简掉**——它决定「过程分怎么拿」。要保留完整解题步骤，别压缩 |
| 经济 9708 / 商务 9609 / 心理 9990 / 历史 9389 | **Level descriptors**（Level 1–4 的整体描述 + indicative content） | 逐点抄没有意义。改成「各 level 的判定要害 + 典型 indicative content + 一份可复用的答题骨架」 |
| 计算机 9618 | 混合：程序题给 pseudocode / 伪码逐行，理论题 point-based | 程序题要保留代码块格式，别当普通文本切 |

**论述型科目还有一条**：它的「章节分类」比理科更模糊，一道 25 分的论述题
经常横跨整个 syllabus。跨章镜像的门槛（化学用 ≥2 分且 ≥15%）在那里几乎肯定要调，
甚至可能整个改成「按 command word（Analyse / Evaluate / Discuss）分类」而不是按 chapter。

## 二、图的多少与类型

| 科目 | 图的情况 | 影响 |
|---|---|---|
| 化学 | 结构式、装置图、dot-and-cross、坐标图；**全是矢量** | caption 锚定裁剪很好用 |
| 物理 | 电路图、光路图、力图、大量坐标图 | 同上，但图更密，`crop.py` 的 y 带宽判据要重调 |
| 生物 | 显微照片（**位图！**）、流程图、大表格 | 位图页的 dpi 意义不同；大表格优先转 Markdown 表而不是裁图 |
| 数学 | 图相对少，但**公式极多** | 重点不在裁图，在公式还原——`$…$` 的量会远大于化学 |
| 经济 / 商务 | 供需图、Extract 文本框（**这才是重点**） | Extract / Source 是题干的一部分，必须完整抄进产物，不能当噪声剥掉 |

**经济 / 商务 / 历史的「Source」「Extract」框**是最容易被噪声剥离逻辑误伤的东西——
它们有边框、有独立排版，很像页面装饰。侦查阶段要专门确认它们没被剥掉。

## 三、Syllabus 的章节结构与统计分组

统计要**按大类不按 chapter**（见 SKILL.md 第 4 条）。分组按各科 syllabus 自己的顶层编排：

| 科目 | 建议分组 |
|---|---|
| 化学 9701（AS） | 1–2 原子与计量 · 3 · 4 · 5 · 6 · 7 · 8（物理化学逐章）· 9–12 无机 · 13–21 有机 · 22 分析 |
| 物理 9702 | 力学 · 热学与物质 · 波 · 电与电路 · 场 · 近代物理 · 实践技能 |
| 生物 9700 | 细胞 · 生物分子 · 酶 · 转运 · 遗传 · 生态与进化 |
| 数学 9709 | 按 component 分（P1 / P3 / M1 / S1），component 内再按 topic |
| 经济 9708 | 基础经济学问题 · 价格机制 · 政府干预 · 宏观 · 国际贸易 |

分组的判据是「**复习时会不会一起看**」。ch10 Group 2 只有几条 outcome，
单独列一行没意义；但 7 Equilibria 分量够，值得单列。

## 四、语言与记法

化学那套定的规矩（写在 vault 的 `CLAUDE.md` 里）：

- 题干、答案、学科术语**全部英文逐字**——这是考试原文，不翻译
- **答案栏与判分栏一个中文字都不许有**（这两栏是拿来对着背的，
  中英混排会让人分不清哪些是 MS 原文、哪些是执行体的话）
- 解释性旁注可以中文，但要另起一行标 `**注**`
- 双重角标用行内 `$…$`，**绝不** `$$…$$`（块公式打断句子，截图难看）

**这些规矩换科目大体照搬**，只是各科的「术语白名单」不同：
化学是元素/官能团/反应机理名，物理是量与单位，经济是 elasticity / opportunity cost 这类，
生物是拉丁学名与专有过程名。

数学要特别注意：**数学的答案几乎全是公式**，`$…$` 的密度会远高于化学，
要提前确认渲染目标（VS Code preview / Obsidian / 网页）对 KaTeX 的支持范围。

## 五、Paper 之间的差异（同一科内）

**别假设 Paper 1 和 Paper 2 一样**，产物格式往往完全不同：

| Paper 类型 | 产物形态 |
|---|---|
| Paper 1（MCQ） | 题干 + 四个选项 + 正确答案 + **为什么其它三个错**（这才是 MCQ 题库的价值所在） |
| Paper 2 / 4（结构题） | 参考实现就是这个 |
| Paper 3 / 5（实验 / planning & analysis） | 答案高度依赖实验设计与误差分析，MS 里的「acceptable range」比具体数值重要 |

MCQ 卷还有一个额外好处：它的 mark scheme 就是一张答案表，
`marks_check` 那套对账逻辑要整个换成「答案表解析」。
