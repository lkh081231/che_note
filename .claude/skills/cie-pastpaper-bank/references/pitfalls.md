全部来自 Chemistry 9701 Paper 2 (2024–2026) 那一轮的实际记录。
机制是通用的，换科目大概率重演。

## subagent prompt 的硬规矩（照抄用）

每一条背后都有一次实际返工。**照抄，不要凭记忆重写。**

```
- **凡带公式、方程、结构式、图表的小问，文本裁题后必须对渲染页视觉核对一遍。**
  抽取器已消掉上下标风险，但版式和符号仍要复核。
- 关键数字（浓度、质量、常数、单位、分值）必须和官方 MS 对账。
- 异常（找不到题 / 页错位 / 题答对不上 / 图裁坏 / 该题实际不属于本章）停下来报，
  不许自圆其说、不许硬凑。
- **报「官方 MS / QP 有缺陷」之前先自己核两遍，并知道主 session 会亲自看图复核。**
  真缺陷是有的（空白格、题号印错、小问被官方撤销、整段 MS 缺失），
  但大多数「官方印错了」的报告其实是执行体自己看错。
- **只用归档目录里的 PDF。** 若怀疑归档文件有问题，停下来报告，
  不要自己去别的站点下载替代品——数据源由主 session 统一把关。
- **答案栏与判分栏只写英文**，一个中文字都不要有。
- **只写自己那个 chapter 文件夹**，不碰别的章、不改已有文件。
- **绝不碰 syllabus 文件**（hook 也会拦）。
- 只准引用正式图目录，不准引用临时渲染目录。
- 完成报告只回三行：做了什么（带数字）· 新发现 · 拿不准的。
```

### 每条的来历

| 规矩 | 不写会发生什么 |
|---|---|
| 视觉核对 | `2Fe(s) + 1½O₂(g) → Fe₂O₃(s)` 被抽成 `2Fe (s) + O(g) → FeO(s)₂ ²³`，分数系数全丢 |
| 报缺陷前核两遍 | 执行体断言「官方 QP 系统性排版缺陷」并声称三重验证；主 session 看图后发现是它数错了 |
| 只用归档 PDF | 执行体自行去第三方站取了替代文件；内容虽对但流程不可控 |
| 不引用临时目录 | 产物里留下指向 gitignore 目录的死链 |
| 答案只写英文 | 存量混进「见上表 …」这类中文，背的时候分不清哪些是 MS 原文 |
| 不补母语译名 | 「cyclopropane（环丙烷）」这类共 6 处，违反「术语一律英文」 |
| 不凭空补标注 | 执行体给一份卷加了「本卷与 XX 同卷」，而那份卷根本不是 |
| 只写自己的文件夹 | 多个 agent 同时改同一文件 |

## 主 session 自己会犯的错

### 成本模型全错

估算「批 1 用 12% 额度」，实际 34%。锚点（「500k Opus uncached ≈ 22%」）本身就是错的。

→ **别建模。用面板前后读数当唯一依据。** 面板上那个百分比是**已用**不是剩余
（验法：看进度条填充方向是否与数字一致）。

### 窗口刷新时刻搞错

以为是固定钟点（01:10 / 06:10 / 11:10），挂了 recurring cron，
结果在额度已用 95% 时触发，白烧一轮。

→ 5 小时窗口**从本窗口第一次调用起算，刷新点会漂**。
挂定时任务一律「**一次性 cron + 刷新时刻后留 10 min 冗余**」，
cron prompt 第一条指令必须是「先复核面板确认窗口真的换了，没换就重挂」。
定时器只是闹钟，门禁是面板读数。

### 在 agent 还在跑的时候执行了重写脚本

`mirror.py` 会重写正本文件。我在 agent 还在编辑时跑了它，脚本按新门槛正确删掉了一个镜像块，
执行体误以为「文件被截断」，又手工重建了一遍。

→ **重写型脚本必须等所有 agent 报完工再跑。** 在脚本 docstring 顶部写警告。

### 文件数 ≠ 题数

看到某章只有 6 个 md 文件就断言「缺两份卷」，实际那章 8 道题分布在 7 份卷里。

→ 用脚本比对「应有的卷 key 集合 vs 实际存在的」，别数文件。

### TODO 里记半截题号

TODO 记了「`w25_21 Q1(b)(iii)` poly(propene)」，实际是**另一个 chapter 的 Q4(b)(iii)**。
我照抄进 subagent prompt，还顺手「核实」了路径——grep 到的是 Q1 的正本，不是那道题。

→ 记位置要写全 `<chapter>/<卷> Q<n>(<小问>)`，或者干脆**只记内容特征**
（「poly(propene) 两个重复单元那题」）让执行体自己 grep。
（这次执行体没照错路径硬做，而是按内容匹配找对了题并报告差异——这是想要的行为，
说明「对不上就报」那条规矩起了作用。）

## 「能力型」章节会被标空

做小问级章节标注时，实测某章 4 道题 38 个小问，**该章一分都没拿到**。

执行体的原则「Identify the reagent → 起始物所属的功能团章」本身没错，但漏了一层：
这些小问**同时**是「分析一条给定合成路线的某一步」，而 syllabus 里有一条 outcome
逐字写着「analyse a given synthetic route in terms of type of reaction and reagents used
for each step of it, and possible by-products」。

**任何科目都有这种「能力型」章节**——它考的是跨内容的技能而不是某块知识，
逐个小问拆下去就会被拆进各个知识章，自己剩不下东西。化学里是
合成路线（ch21）、术语与异构（ch13）、谱图（ch22）；物理里大概是实验设计与误差分析；
经济里是 evaluation 技能。

→ **派活时在 prompt 里点名这些章自己的 outcome**，并且事后用审计脚本查
「主章在自己题里占 0 分」的题。`mirror.py` 和 `verify.py` 都看不见这个问题
（镜像块本来就不计分，总分照样对得上）。

## 脚本层面的小坑

- **GBK 控制台炸在 emoji / `©` 上**（Windows）：脚本里加
  `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8")`，
  **但只在 `if __name__ == "__main__":` 下包**——否则被别的脚本 import 时会关掉调用者的
  stdout，报 `ValueError: I/O operation on closed file`，而且是在文件已经写完之后才炸，
  很容易误判成「脚本失败了」。
- **重写型脚本要能删**：只按 plan 重写文件、从不删除掉出 plan 的文件，
  会在门槛/配置变化后留下一堆幽灵文件。实测留了 16 个过期镜像 md + 40 张孤儿图，
  而验收脚本抓不到。给它加 `--check` dry-run，**删之前先看清单**。
- **保护 hook 会误伤自己的日志**：往日志文件写一段提到被保护文件名的文字时，
  hook 看到命令串里「文件名 + 写操作」同现就拦。
  绕法：先用 Write 工具写暂存文件，再 `cat 暂存 >> 日志`。
- **heredoc 会吃掉 `\\n`**：用 `python - <<'PY'` 写脚本时，字符串里的 `\\n` 可能变成真换行。
  内容复杂就用 Write 工具写文件，别用 heredoc。
