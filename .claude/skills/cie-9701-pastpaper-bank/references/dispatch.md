# 派活：subagent prompt 模板与硬规矩

每一条硬规矩背后都有一次实际的返工。**照抄，不要凭记忆重写。**

## 分工原则

**一个 subagent 独占一个 chapter 文件夹，只写自己那个目录。**

- 写者唯一 → 无写冲突。按卷分工的话，多个 agent 会同时写同一份卷的 md。
- 一个执行体只在一个主题里打转，chemistry 上下文建立一次反复用，
  比按卷跳 5 个不相干主题更省额度也更一致。

每个 subagent **只做 1 个 chapter，做完即结束**——避免长跑失控吃额度。
先开 1 个试点测单章成本，再据此排批。并发起手 2，稳了加到 4。

## 只给本章上下文

给它：本章在 `classification.md` 里的行 + 对应卷的 `_json` 片段 + 已裁好的图 +
含图页的 170dpi PNG + 样板 md 路径。

**不塞整份 classification 全表，不传整卷高 dpi 渲染。**

## 硬规矩（prompt 顶部写死）

```
- **凡带化学式、方程、结构式的小问，文本裁题后必须对渲染页视觉核对一遍。**
  extract.py 已消掉上下标风险，但版式和符号仍要复核。
- 关键数字（浓度、质量、Aᵣ、ΔH、pH、分值）必须和官方 MS 对账。
- 异常（找不到题 / 页错位 / 题答对不上 / 图裁坏 / 该题实际不属于本章）停下来报，
  不许自圆其说、不许硬凑。
- **骨架式（skeletal formula）的每个拐点就是一个碳。** 数碳数前先把拐点数进去。
- **报「官方 MS / QP 有缺陷」之前先自己数两遍，并知道主 session 会亲自看图复核。**
  真缺陷是有的（空白格、题号印错、小问被官方撤销），但「结构式少一个碳」这类几乎都是数错。
- **只用 originalpdf/ 里的 PDF。** 若怀疑归档文件有问题，停下来报告，
  不要自己去别的站点下载替代品——数据源由主 session 统一把关。
- **`**答案**` / `**判分**` 只写英文**，一个中文字都不要有。
- **只写自己那个 chapter 文件夹**，不碰别的章、不改已有文件。
- **绝不碰 ../reference.md**（hook 也会拦）。
- 只准引用 `img/`，不准引用 `_img/`（那是 gitignore 的临时渲染目录）。
```

## 小问级章节标注的 prompt（第二轮才做）

格式 `### (b)(iii) [3] · ch9`（一个空格 + `·` + 一个空格 + `chN`，可 grep）。
只标**带 `[n]` 分值**的小问，题干铺垫行不标；只标**跨章的题**（单章题无歧义，标了浪费额度）。

额外三条：

```
- **标题行带 ⟨镜像⟩ 的题块是脚本生成的，一个字都不能改**；只改本章主管的题块
- **不要被 chapters.py 已写的「兼章」限制住**，1–22 任意一章都能标，
  发现新的要在报告里列出 `卷 题 小问 → chN` 和 syllabus 的 outcome 依据
- 判断不了的列出来，不要瞎标；完成报告只回三行
```

⚠️ **「能力型」章节要在 prompt 里点名它自己的 outcome，否则会被拆空。**
实测 ch21 Organic synthesis 第一遍 4 题 38 小问、ch21 一分没有——执行体的原则
「Identify the reagent → 起始物所属官能团章」本身没错，但漏了 21.1.3
「analyse a given synthetic route in terms of type of reaction and reagents used for each step」。
同类风险：ch13（术语与异构）、ch22（谱图）。

## 主 session 的角色

每章抽查 1 题 + 对账关键数值，**不逐字通读产物**（省 context）。

但**该亲自看的图一定要看**。本次几次关键纠错都是主 session 读图推翻执行体的结论：
ch16 的 C₅H₁₂O₄ 结构、`s24_22` MS 缺页的真实原因、ch3 那次假「文件截断」
（其实是我在 agent 还在跑的时候执行了 `mirror.py`）。

## 完成报告只要三行

长报告浪费主 session 的 context。要求执行体只回：
做了什么（带数字）· 新发现 · 拿不准的。
