Reaction mechanisms13.2.2 · 14.1.3 · 14.2.4 · 15.1.5 · 17.1.3

syllabus 只要求这 4 个 AS 机理。得分点逐字取自 mark scheme。 13.2.2 注：the arrow should begin at a bond or a lone pair of electrons —— 箭尾画错位置直接丢分。

1 · Free-radical substitution14.1.3 · alkane + Cl₂ / UV

Mark scheme 得分点

  1. propagation 1 — C₃H₈ + Cl• → CH₃CH₂CH₂• + HCl
  2. propagation 2 — CH₃CH₂CH₂• + Cl₂ → CH₃CH₂CH₂Cl + Cl•
  3. termination — CH₃CH₂CH₂• + Cl• → CH₃CH₂CH₂Cl
bond fission 类型答 homolytic。 A homolysis · BOD homolytical · I covalent · I photolytic
free radical 定义：species with one or more unpaired electrons。 I lone / single / free / odd number of electrons · R it is an unpaired electron（说成"是一个电子"而非"含未成对电子的物种"）
自由基写法：带不带 • 都接受，但 I 通式 •C₆H₁₃ / CH₃(CH₂)₅•（无位置信息）； I • 位置写错。M2 可对 M1 的错误 alkyl 做 ecf， 但把自由基当阴/阳离子处理则 ecf 不给分。
2 · Electrophilic addition14.2.4 · ethene + Br₂

Mark scheme 得分点 · 5 点制

  1. dipole on Br₂
  2. curly arrow from C=C bond to a Brδ+
  3. curly arrow from Br–Br bond to the other Br
  4. correct intermediate
  5. curly arrow from lone pair on Br⁻ to C⁺
给分换算：5 点 = 3 分 · 4 点 = 2 分 · 3 点 = 2 分 · 2 点 = 1 分 · 1 点 = 0 分
HBr 版本是 4 分制：M1 arrow C=C → H；M2 dipole Hδ+–Brδ− AND arrow from H–Br bond to Br；M3 正确碳正离子 AND 最终产物；M4 arrow from lone pair on Br⁻ to C⁺。 dipole 是独立得分点，漏标就丢 M2。
稳定性问法答 number of alkyl / methyl groups。 I inductive effect（反直觉，不给分）· I number of C atoms · I 只写 tertiary > secondary > primary stability
3 · Nucleophilic substitution SN1 & SN215.1.5–6 · R–Br + OH⁻

Mark scheme 得分点 · SN1

  1. correct dipole (C–Br) AND curly arrow from bond of C–Br to Br（画到略超出 Br 也给分）
  2. correct intermediate（ALLOW 用 R 代表长链）
  3. curly arrow from lone pair on OH⁻ 指向 intermediate 的 C
写错机理不是零分。若画成 SN2：只有当机理显示 OH⁻/NaOH 直接进攻 reactant 且不含独立碳正离子中间体时才按 SN2 判 —— M1 同上；NOT M2（丢掉中间体那一分）；M3 arrow from lone pair on :OH⁻ 指向 reactant 上对应的 C。
NH₃ 做 nucleophile 时多一步（15.1.3(c)）：M1 C–Br dipole + arrow； M2 NH₃ lone pair → C⁺；M3 arrow 表示一条 N–H 键断裂、箭头指向 N（去质子化得中性胺） —— 第三条箭头最常被漏画。
4 · Nucleophilic addition17.1.3 · carbonyl + HCN / KCN

Mark scheme 得分点

  1. curly arrow from lone pair on :CN⁻ to C(δ+)
  2. curly arrow from C=O to O(δ–) AND correct dipole
  3. correct intermediate
  4. curly arrow from lone pair on O:⁻ to H⁺
两个最常丢的分：M1 的箭尾必须画在 :CN⁻ 的 孤对上（不是 HCN 分子）；M4 的第四条箭头（alkoxide 拿 H⁺）常被整条漏掉。
产物类别答 hydroxynitrile。 chiral centre 定义 —— atom / carbon with four different atoms / (functional) groups attached；R 说成 molecules / compounds； R "4 个不同 alkyl group"（应为 4 个不同基团）。

free radical 定义与稳定性s26_22

定义： (species) with one or more unpaired electrons

  • Ilone / single / free / odd number of electrons
  • Rit is an unpaired electron —— 必须说"物种"，不是"电子"

稳定性 1° < 2° < 3° 的原因： number of alkyl / methyl groups

  • Anumber of C atoms bonded to the central carbon / branches / R groups
  • Iinductive effect —— 反直觉，不给分
  • Inumber of C atoms · number of hydrogens
  • I只写 tertiary > secondary > primary stability
手性中心与立体异构s26_22 · s26_23

chiral centre： atom / carbon with four different atoms / (functional) groups attached

  • R说成连接四个不同的 molecules / compounds（必须是 atoms / groups）
  • R"C 连 4 个不同 alkyl group"（应为 4 个不同基团）

cis-trans 异构的解释

  • I只写 double bond（分子另有 C=O 时不够具体）
  • Imovement（rotate / twist / spin 可以）
  • RC=C 两端接的是 different compounds / molecules
命名与结构式s26_22 · s26_23
  • R编号方向反了（未取最小定位号），如 6-chlorohexane → Max 1
  • A漏连字符（missing hyphen）不扣分
  • I拼写错误但前后一致（1-chlorhexane）→ Max 1
  • I题目要画结构却写了名字
  • I只写分子式（C₄H₈ 不算结构）
  • Rconnectivity 错误（写成 C−H−O）→ Max 1
骨架式的每个拐点就是一个碳。数碳数前先把拐点数进去。
[O] / [H] 配平的固定套路s25_22 · s25_21

13.2.1 允许用 [O] 表示氧化剂的一个氧、[H] 表示还原剂的一个氢。

  • A1° alcohol → aldehyde 耗 1[O]；→ COOH 耗 2[O]
  • Aaldehyde/ketone → alcohol 耗 2[H]
  • ACOOH → CH₂OH 恒耗 4[H] 并产 1 个 H₂O
例：CH₃CH₂COOH + 4[H] → CH₃CH₂CH₂OH + H₂O； 二元酸则 8[H] + 2H₂O。 LiAlH₄ 不还原 C=C —— 分子里同时有 COOH 和 C=C 时，只有 COOH 被还原。
